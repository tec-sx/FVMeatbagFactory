# 3D Male Base Mesh

A low-poly male base mesh in a T-pose with a full Blender metarig (56 bones) and skin weights.
No materials, textures or animations. It faces +X (glTF convention is +Z), so the Demo camera starts at yaw 90°.

- Author: orange-juice-games (https://orange-juice-games.itch.io), packaged by BoQsc
- Source: https://github.com/BoQsc/Godot-Male-Base-Mesh, latest release `male_base_mesh.zip` as of 2026-10-27 (
  exported with Blender glTF I/O 4.3.47)
